# Le goût du créateur : verdicts et leçons

Fichier de maintenance : l'IA ne le lit pas pendant une vidéo. Chaque verdict donné sur une vidéo
réelle, avec la leçon la plus étroite qu'il justifie et l'endroit où elle vit maintenant dans le
skill `studio`. Une nouvelle règle n'entre dans le skill que si elle vaut pour toutes les offres,
pas seulement pour la vidéo jugée ; sinon elle reste ici.
